# Individual Household Electric Power Consumption

## Información General

El dataset **Individual Household Electric Power Consumption** contiene registros de consumo energético doméstico correspondientes a un hogar ubicado en Francia.

El conjunto de datos incluye mediciones eléctricas tomadas durante un periodo cercano a cuatro años y constituye uno de los datasets más utilizados en investigaciones relacionadas con:

- análisis de series temporales,
- predicción de demanda energética,
- detección de anomalías,
- forecasting,
- y aprendizaje automático aplicado a energía.

## Descripción del Contenido

El dataset contiene mediciones eléctricas registradas minuto a minuto dentro de un hogar residencial.

Incluye variables relacionadas con:

- potencia activa,
- potencia reactiva,
- voltaje,
- intensidad de corriente,
- y submediciones de diferentes zonas del hogar.

---

## Variables Principales

| Variable | Descripción |
|---|---|
| Date | Fecha |
| Time | Hora |
| Global_active_power | Potencia activa global |
| Global_reactive_power | Potencia reactiva global |
| Voltage | Voltaje |
| Global_intensity | Intensidad global |
| Sub_metering_1 | Submedición zona 1 |
| Sub_metering_2 | Submedición zona 2 |
| Sub_metering_3 | Submedición zona 3 |

---

## Frecuencia Temporal

Las mediciones fueron registradas cada:

- 1 minuto

---

## Uso dentro del Proyecto

Este dataset será utilizado para:

- evaluación de modelos de series temporales,
- análisis de robustez,
- validación cruzada entre datasets,
- y comparación de desempeño frente a diferentes distribuciones de consumo energético.
