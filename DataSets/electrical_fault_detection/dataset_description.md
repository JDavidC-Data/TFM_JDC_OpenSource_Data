# Electrical Fault Detection and Classification

## Información General

El dataset **Electrical Fault Detection and Classification** contiene variables eléctricas etiquetadas con diferentes tipos de fallos eléctricos y está orientado al entrenamiento y evaluación de modelos supervisados de clasificación.

El dataset es utilizado en tareas relacionadas con:

- detección de anomalías,
- clasificación de fallos eléctricos,
- diagnóstico de sistemas eléctricos,
- y aprendizaje automático aplicado a redes eléctricas inteligentes.

---

## Fuente

Kaggle:

https://www.kaggle.com/code/jaison14/electrical-fault-detection-and-classification/output

---

## Descripción del Contenido

El dataset incluye variables eléctricas obtenidas a partir de simulaciones o mediciones de sistemas eléctricos bajo diferentes condiciones operativas.

Las observaciones se encuentran etiquetadas según el tipo de fallo presente en el sistema.

---

## Variables Generales

El dataset puede incluir variables relacionadas con:

- voltaje,
- corriente,
- potencia,
- frecuencia,
- estado del sistema,
- y etiquetas de clasificación de fallos.

---

## Tipos de Fallos

Dependiendo de la versión utilizada, las etiquetas pueden incluir:

- Fallo monofásico
- Fallo bifásico
- Fallo trifásico
- Operación normal
- Cortocircuitos
- Fallos a tierra

---

## Uso dentro del Proyecto

Dentro de este trabajo el dataset será utilizado para:

- evaluación de modelos supervisados,
- análisis de transferencia entre datasets,
- comparación de algoritmos de clasificación,
- y validación de robustez experimental.
